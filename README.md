# Kanary Calling

Marketing website for Kanary Calling, a founder-led fractional B2B cold calling service.

## Pages

- Home
- What we do
- Who we help
- About
- FAQ
- Contact
- Privacy
- Terms

## Local development

```bash
pnpm install
pnpm dev
```

Create a production build with `pnpm build`.

## Before public launch

Connect the contact form to the preferred business email or scheduling service. Review the privacy policy and terms with the final legal entity, mailing address, and governing law.
